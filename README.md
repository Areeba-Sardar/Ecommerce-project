# Ecommerce Internship Project

A responsive Ecommerce Web Application developed using Python Flask, HTML, CSS, SQLite, and Authentication System.

This repository contains all internship tasks divided into 3 weeks.

---

# Technologies Used

- Python
- Flask
- Flask SQLAlchemy
- Flask Login
- HTML5
- CSS3
- SQLite
